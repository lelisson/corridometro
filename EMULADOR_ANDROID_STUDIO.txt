ERRO: "The emulator process for AVD Pixel_7 has terminated"
=============================================================
O emulador CRASHOU ao abrir (fecha sozinho). Tente nesta ordem:

1) Device Manager > Pixel_7 > menu ... > Wipe Data > sim
2) Depois: Cold Boot Now
3) PowerShell:
     cd c:\corridometro
     .\start-emulator-safe.ps1 -AvdName "Pixel_7"

4) Se ainda fechar, APAGUE o Pixel_7 e crie outro AVD:
   - Pixel 6 (nao 7)
   - API 34, imagem Google Play, x86_64
   - Show Advanced Settings > RAM 2048, Internal 2048
   - Graphics: Automatic ou Software - GLES 2.0

5) Windows:
   - Ativar "Plataforma de Maquina Virtual do Windows"
   - Reiniciar o PC
   - SDK Manager > SDK Tools > Android Emulator Hypervisor Driver (Intel)

6) Conflito Hyper-V: se usa WSL2/Docker pesado, feche e teste de novo.

7) Celular USB (alternativa): .\preview-app.ps1

----------------------------------------------------------------------
ERRO: "Timed out waiting for emulator to come online"
=====================================================

O Android Studio nao conseguiu ligar o emulador em 5 minutos.
Faca nesta ordem:

----------------------------------------------------------------------
SOLUCAO RAPIDA (recomendada)
----------------------------------------------------------------------
1. Feche emuladores travados (X na janela do celular virtual)

2. PowerShell na pasta do projeto:
     cd c:\corridometro
     .\start-emulator.ps1

3. Espere aparecer "Emulador ONLINE"

4. No Android Studio: Run > Corridometro (oficial)
   (o device ja deve estar selecionado na barra)

----------------------------------------------------------------------
SE AINDA FALHAR
----------------------------------------------------------------------
A) Device Manager > menu ... no AVD > Cold Boot Now
   (ou Wipe Data se estiver corrompido)

B) Crie AVD novo:
   Pixel 6 | API 34 | imagem com Google Play | x86_64

C) Windows - aceleracao:
   - Configuracoes > Sistema > Recursos opcionais
   - Ative "Plataforma de Maquina Virtual do Windows"
   - Reinicie o PC
   Android Studio > SDK Manager > SDK Tools >
     marque "Android Emulator Hypervisor Driver" (se Intel)

D) Antivirus / Hyper-V:
   Alguns PCs demoram na 1a boot; deixe a janela do emulador abrir
   ate ver a tela inicial do Android antes de clicar Run.

E) Celular real (mais rapido):
   - Depuracao USB ativa
   - Cabo USB
   - .\preview-app.ps1

----------------------------------------------------------------------
NAO USE RUN PARA LIGAR O EMULADOR
----------------------------------------------------------------------
Sempre: emulador ja aberto -> depois Run.
Isso evita o timeout de 300 segundos.
