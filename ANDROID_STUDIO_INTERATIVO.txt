CORRIDOMETRO — APP INTERATIVO NO ANDROID STUDIO
================================================

Use isto para rodar o app de verdade no emulador (tocar, navegar, salvar jornada).

----------------------------------------------------------------------
PASSO 0 — UMA VEZ (configurar o botao Run)
----------------------------------------------------------------------
No PowerShell, na pasta do projeto:

  cd c:\corridometro
  .\setup-android-studio.ps1

Isso copia as configuracoes "Corridometro (oficial)" e "Corridometro (login)"
para o Android Studio.

----------------------------------------------------------------------
PASSO 1 — ABRIR O PROJETO
----------------------------------------------------------------------
1. Android Studio > File > Open
2. Escolha a pasta: c:\corridometro
3. Aguarde "Gradle Sync" terminar (barra inferior)

----------------------------------------------------------------------
PASSO 2 — EMULADOR
----------------------------------------------------------------------
1. Tools > Device Manager
2. Se nao tiver aparelho virtual:
   - Create Device > Pixel 6 (ou similar)
   - System Image: API 34 ou 35 (Google APIs)
   - Finish
3. Clique no triangulo Play ao lado do emulador para iniciar
   OU no PowerShell: .\start-emulator.ps1
   (espere "Emulador ONLINE" antes do Run)

----------------------------------------------------------------------
PASSO 3 — RODAR O APP (INTERATIVO)
----------------------------------------------------------------------
IMPORTANTE: emulador ja ligado ANTES do Run (evita timeout 300s).
Se deu erro de timeout: EMULADOR_ANDROID_STUDIO.txt

1. Na barra superior, ao lado do botao Run verde:
   - Selecione: Corridometro (oficial)
   - Ao lado, escolha o emulador que esta ligado
2. Clique Run (triangulo verde) ou Shift+F10

O app instala e abre no emulador. Navegue nas abas Inicio e Jornada.

Variante com login Google obrigatorio:
  - Selecione: Corridometro (login)
  - Requer app/google-services.json (veja FIREBASE_SETUP_LOGIN.txt)

----------------------------------------------------------------------
SE O RUN NAO APARECER
----------------------------------------------------------------------
1. View > Tool Windows > Build Variants
2. Modulo "app" > escolha: standardDebug (oficial) ou loginDebug
3. Run > Edit Configurations > + > Android App
   - Nome: Corridometro oficial
   - Modulo: Corridometro.app.main
   - Ou rode de novo: .\setup-android-studio.ps1

----------------------------------------------------------------------
ALTERNATIVA SEM ANDROID STUDIO (PowerShell)
----------------------------------------------------------------------
  .\preview-app.ps1

(emulador ou celular USB ja conectado)
