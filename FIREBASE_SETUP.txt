COMO SALVAR OS DADOS NA CONTA GOOGLE (Firebase)
================================================

Hoje o app guarda os dados LOCALMENTE no celular:
  /data/data/com.corridometro/databases/corridometro.db

Para copiar para a CONTA GOOGLE (nuvem), configure o Firebase uma vez:

1) Acesse https://console.firebase.google.com/
2) Crie um projeto (ex.: Corridometro)
3) Adicione um app Android com pacote: com.corridometro
   (Versao com login obrigatorio: veja FIREBASE_SETUP_LOGIN.txt — pacote com.corridometro.login)
4) Baixe o arquivo google-services.json
5) Coloque em: corridometro/app/google-services.json
6) No Firebase Console, ative:
   - Authentication > Sign-in method > Google (ativar)
   - Firestore Database > Criar banco (modo producao ou teste)
7) Regras do Firestore (Console > Firestore > Regras), para comecar:

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }

8) Sync Gradle no Android Studio e gere o APK de novo (build-apk.ps1)

No app: aba Inicio > Entrar com Google > seus dados sobem para:
  users/{seu-uid}/work_shifts
  users/{seu-uid}/expenses

Trocou de celular? Entre com a mesma conta Google e toque em Sincronizar.
