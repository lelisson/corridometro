CONFIGURAR FIREBASE — VERSAO COM LOGIN (com.corridometro.login)
================================================================

Esta variante EXIGE Firebase para o motorista entrar com Google.
O app mostra um checklist na tela ate o APK estar configurado.

VALIDAR NO PC (antes de instalar no celular):
  .\check-firebase-setup.ps1

----------------------------------------------------------------------
PASSO A PASSO
----------------------------------------------------------------------

1) CRIAR PROJETO
   https://console.firebase.google.com/
   > Adicionar projeto (ex.: Corridometro)

2) REGISTRAR O APP ANDROID DA VERSAO LOGIN
   Project Overview > Android
   Nome do pacote (obrigatorio, copie exatamente):
     com.corridometro.login
   (Opcional: registre tambem com.corridometro se usar o app padrao)

3) BAIXAR google-services.json
   Coloque em:
     corridometro/app/google-services.json
   (nao commite no Git — ja esta no .gitignore)

4) ATIVAR LOGIN GOOGLE
   Authentication > Sign-in method > Google > Ativar > Salvar
   Escolha o e-mail de suporte do projeto se pedir.

5) CRIAR FIRESTORE
   Firestore Database > Criar banco
   Modo producao ou teste (para testes, teste e mais rapido).

6) REGRAS DO FIRESTORE
   Firestore > Regras > cole o conteudo de firestore.rules (raiz do projeto):

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }

   > Publicar

7) SHA-1 / SHA-256 (evita erro ao logar no celular)
   No PC, na pasta do projeto:
     .\gradlew.bat signingReport
   Copie SHA-1 e SHA-256 da variante loginDebug
   Firebase > Project Settings > Your apps > com.corridometro.login
   > Add fingerprint > cole SHA-1 e SHA-256

8) GERAR APK LOGIN
     .\build-apk-flavor.ps1 login
   Instalar:
     releases/login/corridometro-v1.4.1-com-login-6-debug.apk
   ou:
     .\preview-app.ps1 -Flavor login

----------------------------------------------------------------------
NO CELULAR (MOTORISTA)
----------------------------------------------------------------------
1) Abrir o app "Corridometro (Login)"
2) Toque em "Continuar com Google"
3) Escolher a conta Google
4) Dados sincronizam em users/{uid}/work_shifts e expenses

----------------------------------------------------------------------
PROBLEMAS COMUNS
----------------------------------------------------------------------
- Botao Google nao aparece / tela "Configurar Firebase"
  -> Falta google-services.json ou APK antigo. Refaca passos 3 e 8.

- Erro 10 / DEVELOPER_ERROR ao logar
  -> SHA-1 nao cadastrado no Firebase (passo 7).

- Login ok mas sync falha
  -> Firestore nao criado ou regras erradas (passos 5 e 6).

- App padrao (sem login obrigatorio): use FIREBASE_SETUP.txt e pacote com.corridometro
